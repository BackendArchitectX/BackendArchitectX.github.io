03 / Upstream engineering

Upstream fixes at failure boundaries.

The signal is not diff size. It is whether the failure mode is real, the fix belongs at the right boundary and the regression test proves it.

AutoMQ#3493 · Merged

Skip AutoBalancer metrics reporter on controller-only nodes

Process-role handling prevented broker listener resolution and reporter startup where the broker role was absent, with regression coverage across role combinations.

Make cached RPC connections endpoint-aware

Connection identity moved from logical UID alone to UID + host + port so metadata endpoint changes cannot silently keep routing through a stale physical connection.
